## EN English

### About

This site is my CV, built to show what I do in IT support rather than just list it. It highlights the **50+ computers I have repaired** and my hands-on experience from two IT support internships (PC.Clinic and Click PC), plus my current work in Trust & Safety.

👉 **[Open the live site](https://bperiquito.github.io/itsupport/)**

### What you will find

| Section | What it shows |
|---|---|
| **Repair counter** | A "50+ computers repaired" counter that animates on load, with 50 small computers that light up as it counts. Click one to see a typical issue type. |
| **IT support internships** | PC.Clinic and Click PC shown as two "tickets", each with the full list of tasks. |
| **Quick diagnostic** | A button that runs the usual repair checks one by one: startup, performance, connectivity, peripherals, backup and malware. |
| **Toolbox** | Skills in clickable tabs: Windows and end-user support, identity and security, IT operations, data and productivity, development, ways of working. |
| **Experience** | Trust & Safety at Accenture, Assistant Manager at Lidl, freelance photography and a database internship. |
| **Education and certifications** | Vocational course in Information Technology (EQF Level 4) and an expandable list of certifications. |
| **Open a ticket** | Contact by email or LinkedIn, each with a copy button. |

### Features

- 🌍 **PT/EN switch:** all text changes language instantly.
- 🌗 **Light/dark theme:** follows the system setting, with a manual toggle.
- 📱 **Responsive:** designed for phones and desktops.
- ♿ **Accessible:** visible keyboard focus, real buttons and links, `aria-live` notes, and animations skipped when the system asks for reduced motion.
- ⚡ **Fast:** one self-contained file, no build step and no frameworks.

### Tech

- Plain HTML, CSS and JavaScript in a single file (`index.html`).
- Fonts from Google Fonts (Bricolage Grotesque and Public Sans), with system fallbacks.
- Profile photo embedded in the file as a small base64 JPEG.
- Hosted on GitHub Pages.

### Run locally

```bash
git clone https://github.com/bperiquito/itsupport.git
cd itsupport
```

Then open `index.html` in your browser. No installation needed.

### Project structure

```text
itsupport/
├── index.html   # the whole site: structure, styles and scripts
└── README.md    # this file
```

## 🇵🇹 Português

### Sobre

Este site é o meu CV, feito para mostrar o que faço em IT support em vez de apenas o listar. Destaca os **mais de 50 computadores que já reparei** e a minha experiência prática de dois estágios de suporte IT (PC.Clinic e Click PC), além do meu trabalho atual em Trust & Safety.

👉 **[Abrir o site](https://bperiquito.github.io/itsupport/)**

### O que encontras

| Secção | O que mostra |
|---|---|
| **Contador de reparações** | Um contador "50+ computadores reparados" que anima ao abrir, com 50 pequenos computadores que se acendem à medida que conta. Ao clicar num, aparece um tipo de problema. |
| **Estágios de suporte IT** | PC.Clinic e Click PC como dois "tickets", cada um com a lista completa de tarefas. |
| **Diagnóstico rápido** | Um botão que corre as verificações habituais de uma reparação, uma a uma: arranque, desempenho, conectividade, periféricos, cópia de segurança e malware. |
| **Caixa de ferramentas** | Competências em separadores clicáveis: Windows e apoio ao utilizador, identidade e segurança, operações IT, dados e produtividade, desenvolvimento, métodos de trabalho. |
| **Experiência** | Trust & Safety na Accenture, Assistant Manager no Lidl, fotografia freelancer e estágio de Database. |
| **Formação e certificações** | Curso profissional em Information Technology (QEQ nível 4) e lista de certificações expansível. |
| **Abrir um ticket** | Contacto por email ou LinkedIn, cada um com botão para copiar. |

### Funcionalidades

- 🌍 **Botão PT/EN:** todo o texto muda de língua instantaneamente.
- 🌗 **Tema claro/escuro:** segue a definição do sistema, com botão manual.
- 📱 **Responsivo:** pensado para telemóvel e computador.
- ♿ **Acessível:** foco de teclado visível, botões e links reais, notas com `aria-live` e animações desligadas quando o sistema pede movimento reduzido.
- ⚡ **Rápido:** um único ficheiro, sem build e sem frameworks.
